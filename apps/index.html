How to install

  1. 1
    Tap Install on this page, on your Android phone. The file downloads (it ends in .apk).
  2. 2
    Open the file. The first time, Android asks you to allow installs from your browser. Turn that on, go back, and tap Install.
  3. 3
    If Play Protect warns you that it doesn't know the app, tap More details → Install anyway. That's because the app isn't on the Play Store.
Will an update delete my data?

No. A new build installs over the old one and keeps your playlists, shelf, favourites and settings. If Android says "App not installed", the old copy was signed with a different key. Uninstall it once, then install again.

Can I update without coming back to this page?

Yes, once an app has the in-app updater. It checks for a new build when you open it and offers an Update button. Android still asks you to confirm the install. Apps can't update themselves silently outside the Play Store.

Is it safe?

Every download comes straight from the app's GitHub releases, and the page shows each file's SHA-256 fingerprint so you can check it. The source code is public on GitHub.
